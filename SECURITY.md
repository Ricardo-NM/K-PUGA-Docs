# Seguridad y divulgacion responsable

Este repositorio documenta K-PUGA a nivel publico y no debe contener informacion sensible.

## No publicar

- Codigo fuente del sistema privado.
- Credenciales, tokens, secretos o variables de entorno.
- Cadenas de conexion, IPs internas o rutas de infraestructura privada.
- Consultas SQL, nombres de tablas o modelos internos.
- Datos reales de clientes, usuarios, operaciones o documentos.
- Capturas de pantalla sin anonimizar.
- Endpoints completos o reglas internas que faciliten abuso.

## Reportes

Si encuentras informacion sensible publicada por error, abre un issue con una descripcion minima o contacta al propietario del repositorio de forma privada. No repliques la informacion sensible en discusiones publicas.
