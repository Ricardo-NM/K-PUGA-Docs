# Contribuir

Las contribuciones son bienvenidas si ayudan a mejorar claridad, arquitectura, redaccion, diagramas o criterios de seguridad documental.

## Reglas

- No incluir codigo fuente privado.
- No publicar datos reales, secretos, credenciales, endpoints completos ni consultas.
- No agregar capturas sin anonimizar.
- Usar ejemplos ficticios cuando sea necesario.
- Mantener el enfoque en explicacion publica de alto nivel.

## Antes de abrir un pull request

Ejecuta:

```bash
npm run docs:build
```

Tambien revisa que no existan cadenas sensibles en los archivos Markdown o configuracion del sitio.
